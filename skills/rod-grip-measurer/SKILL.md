# Role: 握把長度量測器 (Rod Grip Measurer)

## Description

`rod-curve-generator` 需要知道「從竿尾算起哪一段不會彎」——持竿時的固定端是**手**，不是竿尾。
少了這一段，模型會用一根過長的槓桿去達成同樣的竿尖下沉量，**彎得太靠元端**。

多數廠牌的規格表沒有グリップ長這一欄。但**官方商品圖自帶一把尺**：拆成兩節平放的商品圖，
**元節的像素長度就對應官方公佈的仕舞寸法**。本 Skill 就是靠這把尺量出握把長度。

**本 Skill 的產出只有兩個數字**：握把長度（cm）與可利用竿長（cm ＝ 全長 − 握把）。

---

## 🔴 職責邊界（務必遵守）

| 問題 | 由誰回答 |
|---|---|
| 這支竿的握把多長、可利用竿長多少 | **本 Skill** |
| 握把長度會怎麼影響手感／操作 | `rod-spec-decrypter` |
| 這段剛性會讓竿子彎成什麼形狀 | `rod-curve-generator` |

1. 🔴 **嚴禁解釋握把長度對手感或拋投的影響。** 本 Skill 只量長度。
2. 🔴 **可利用竿長不是拋投距離的預測值。** 拋得多遠還牽涉揮竿角速度、竿身回彈速度
   （`3DX` 那類動態技術）、餌重與線徑——**回彈速度正是靜態模型畫不出來的那一半**。
   它的正當用途是：兩支全長相同的竿，可能因為握把差 10cm 而有完全不同的作用長度。
3. **可信度一律 🟡。** 全長是原廠的、握把是量的，相減出來的也只能是 🟡。
   引用時**必須**標明「本 skill 由官方商品圖量測，非原廠公佈規格」。

---

## 🔴 Step −1：先確認原廠真的沒給（不可跳過）

**本 Skill 是備案，不是首選。** 它存在的唯一理由是「規格表沒有這一欄」。

| 情況 | 處置 | 可信度 |
|---|---|---|
| 官方規格表**有**グリップ長／リアグリップ長 | **直接用官方值，不跑本 Skill** | 🟢 |
| 官方規格表**沒有**，但拿得到商品圖 | 執行本 Skill | 🟡 |
| 規格表沒有、商品圖也拿不到 | **停止，回報「未取得」** | ❌ 不輸出數值 |

⚠️ 「DAIWA Heartland 的規格欄沒有グリップ長」是**已逐項核對過的事實**
（該頁欄位只有：全長／継数／仕舞寸法／自重／先径・元径／ルアー／ライン／カーボン含有率），
**但那是這個系列的事實，不是通則**——別的廠牌與系列是有列グリップ長的。

🔴 **不得跳過 Step −1 直接量圖**：那等於用 🟡 的量測值取代現成的 🟢 官方數據。

---

## 🔴 退場條件：量不出來就是量不出來，不准推測

腳本在下列情況會**失敗並且不輸出任何握把數值**。看到這些訊息時，**照實回報卡在哪一層**：

| 卡點 | 腳本的判定 |
|---|---|
| 拿不到圖 | 檔案不存在／下載失敗／下載到的不是圖片 |
| 圖的型態無法判定 | 切出 ≥3 條帶 |
| 找不到握把 | 沒有連續夠長的粗段 |
| 數值不合理 | 握把佔全長落在 10〜25% 之外 |

**三種結局必須分開講，不得混為一談**（沿用 `rod-spec-decrypter` 的措辭守則）：

- 「**原廠從未定義**」——規格表根本沒有這個欄位
- 「**資料在別處**」——規格表沒列，但商品圖量得到
- 「**查無此資料**」——圖拿不到，或拿到了但解析不出

🔴 **嚴禁用公式回填。** 實測 12 支中，同樣是 218cm 的六支，握把從 30.1 到 40.8cm——
**同長度內就差 10.7cm**。最好的規則（紡車／貝爾各自對全長做線性）RMS 仍有 1.94cm。
任何「這個長度的竿大概幾公分」都是把雜訊寫進下游的圖裡。

✅ **下游已經正確處理「沒有量測值」，不需要為了讓圖畫得出來而硬補**：
`rod-curve-generator` 會在 stderr 警告、圖上 `[Model Parameters]` 標「未量測」、
灰帶與黑色握把棒都不畫、且**不套用**握把剛性。那是正確行為，不是待修的缺陷。

## 適用範圍（Scope）

**已驗證支援：DAIWA 日本官網（daiwa.com）的商品圖，12 支全數通過回歸測試。**

支援兩種圖型，腳本會自動判定並在輸出中標明：

| 圖型 | 比例尺來源 | 需要的參數 |
|---|---|---|
| **拆節平放**（兩節上下並排） | 元節像素長 ÷ **仕舞寸法** | `--length-cm`＋`--closed-cm` |
| **整支組裝**（單一條帶） | 總像素長 ÷ **全長** | `--length-cm` |

⚠️ **其他廠牌未驗證。** 商品圖的排版未必相同（未必拆節平放、未必以仕舞寸法為長邊、
可能帶有其他物件）。遇到非 DAIWA 來源時**先請使用者確認圖的型態**，並把交叉檢查的結果
一併轉達，不要看到有數字就當成量對了。

## Execution Logic

### Step 0: 取得官方商品圖與規格

從官方產品頁取得該型號的商品圖網址，以及**全長**、**仕舞寸法**（拆節圖必要）。
先径／元径／種類為選填，但**有就一定要帶上**——它們是比例尺的交叉檢查依據。

### Step 1: 執行量測

```bash
uv run <skill_dir>/scripts/measure_grip.py measure \
    --image <網址或本機路徑> --model 722MLRSS-24 \
    --length-cm 218 --closed-cm 113 \
    --tip-dia-mm 1.6 --butt-dia-mm 9.4 --category S \
    --out-dir <複驗圖輸出目錄>
```

🔴 **路徑一律用 `<skill_dir>/scripts/...`**。安裝時 `bin/install.js` 會把 `<skill_dir>`
換成實際絕對路徑；寫成裸檔名或相對路徑，注入到其他編輯器之後會找不到腳本。

### Step 2: 🔴 看複驗圖（不可跳過）

腳本一定會輸出 `<型號>_grip_check.png`：元節放大，紅線畫在偵測到的握把前緣。

**必須實際開圖確認紅線落在前握把前緣**（EVA／軟木結束、露出裸竿身的那一點），
並把圖給使用者看過。

⚠️ **數字看起來合理不代表位置抓對了。** 這是唯一能抓到「抓錯帶」「圖其實是組裝好的整支」
「比例尺用錯」這類錯誤的一步。第一版的偵測邏輯曾把 `722MLRSS-24` 量成 96.5cm
（真值 34.5cm）——被最大導環的單點厚度尖峰騙了。

### Step 3: 檢視交叉檢查

腳本會輸出四項比例尺交叉檢查。**每一項都要看，並且照實轉達**：

| 檢查 | 對照 |
|---|---|
| 竿尖最細處 | 官方先径 |
| 握把前緣上方的裸竿身 | 官方元径 |
| EVA 握把最粗 | 18〜32mm 常識範圍 |
| 兩節像素和 − 全長 ＝ 接管重疊 | 應為正值、約 5〜8cm |

- `✅` 通過、`⚠️` 偏差過大、`⊘ 無法檢查` 資料不足。
- 🔴 **`⊘ 無法檢查` 不等於通過。** 低解析圖（約 9 px/cm）的 1.6mm 竿尖只有 1.3px，
  偵測不到，先径與接管重疊兩項會變成無法檢查——那是偵測極限，
  **不影響元節與握把長度**，但也**不能拿來當作量對了的證據**。
- 出現 `⚠️` 時不代表一定錯，但**必須連同數字一起報給使用者**，由人判斷。

### Step 4: 寫回量測表

確認無誤後，加 `--write` 重跑，或手動把腳本印出的資料列貼進
`rod-curve-generator/references/measured_grip_lengths.md` 的 **§1 量測表**與 **§1-b 可利用竿長**。

`--write` 會做三件事：依握把長度排序插入兩張表 → **寫完自己再讀一次複查**
（讀回來的必須真的是握把、筆數要對、值要落在 15〜60cm）→ 跑下游的 `validate_ccs.py`。
**複查失敗會自動回滾**，不會留下半成品。型號已存在時需加 `--force`。

🔴 **寫完一定要重畫圖**，否則磁碟上的圖還是舊的：

```bash
uv run <rod-curve-generator>/scripts/rod_curve_cli.py plot-zenaq --input ... --output-dir ...
uv run <rod-curve-generator>/scripts/rod_curve_cli.py plot-engineering --input ... --output-dir ...
```

## 回歸測試

動到偵測邏輯（切帶、厚度、握把前緣判定、比例尺）**一定要跑**：

```bash
uv run <skill_dir>/scripts/validate_grips.py
```

它會逐支下載 `references/reference_photos.md` 裡的 12 張官方圖重量一次，
**誤差須 < 1.0cm 且圖型判定一致，12 支全過才算通過**。

- 抓不到圖會標 `SKIP` 並在結尾明確列出，**跳過不計為通過**；全部跳過則失敗。
- 官網換圖導致網址失效時，正確處置是**回產品頁重抓網址並更新答案卷**，
  **不是**放寬門檻、也不是把該支從答案卷裡刪掉。
- 無網路時可用 `--image-dir <本機目錄>` 離線測。

## Common Mistakes

- **跳過 Step −1** 就開始量圖——先確認原廠是不是根本就有這個欄位。
- **沒開複驗圖就相信數字**。這是本 Skill 唯一的人工把關點。
- 把 `⊘ 無法檢查` 讀成「檢查通過」。
- 量不出來時改用「同級竿大概幾公分」回填——**這正是本 Skill 存在要避免的事**。
- 把可利用竿長講成拋投距離或拋投性能指標。
- 寫進量測表後忘記重畫圖，然後以為修改沒生效。
