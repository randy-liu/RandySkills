# ダイワ（DAIWA）型號命名規則辭典

這份文件是 DAIWA 釣竿**型號字串的解碼規則**，供 `SKILL.md` 的 **Step 0（型號自動解碼）**使用。

> 🔴 **三份 reference 的分工**
> 本檔 = **型號字串怎麼拆**（一次性流程，Step 0 使用）
> `daiwa_technology.md` = **技術名詞是什麼意思**（查表，Step 2 反覆使用）
> `daiwa_<系列>_features.md` = **這一支竿是什麼**（機種級事實，**僅在 prompt 指名該系列時**載入）
> 分析 DAIWA 釣竿時，**前兩份必須載入**。

> 🔴 **本檔為何保留具體型號——它們是「解析驗證基準」，不是竿款名冊**
>
> `daiwa_technology.md` 禁止登錄型號，本檔**不適用**該規則。本檔的型號是文法規則的**錨點**：
> 沒有 `7112MRB-25`，長度欄位「2 位數 vs 3 位數」的消歧就失去實例；
> 沒有 `722LRSB-24 → 72/2/L/R/S/B` 的逐欄對照，額外 `S` 的插入位置就無從驗證。
> 抽掉會直接造成 Step 0 解析錯誤。
>
> 兩者的分界是**「有沒有天花板」**：
> - 搭載清單 = 每出一支新竿就長一列 → **無上限，不得寫入任何字典**。
> - 解析驗證基準 = 每條文法規則一組最小樣本 → **有上限，必須留下**。
>
> ⚠️ **因此本檔的型號以「覆蓋每條文法規則的最小樣本」為限，嚴禁擴充為搭載清單或竿款名冊。**
> 新增型號前先問：它是否驗證了某條現有規則無法被既有樣本覆蓋的部分？否則不要加。
>
> 🔴 **使用限制**：這些樣本**僅供文法驗證**。分析任何竿款時，**不得**援引它們作為比較對象、
> 類比依據或物理推演素材——與 `SKILL.md` 守則 3 一致。

## 0. 使用原則（務必遵守）

1. **逐欄位比對，不得跳過**：型號字串必須從左到右依序拆解，每個字元都要有歸屬。
2. **🔴 遇到本檔未涵蓋的字元，一律不臆測**：
   直接在報告中揭露「**該欄位不在 Skill 命名字典庫中，需要更新 Skill**」，並且**該字元不得作為後續任何物理推演的依據**。
3. **確認長度吻合**：拆解出的長度應與官方「全長」規格互相驗證（1 ft = 0.3048 m）。若不吻合，代表拆解有誤，須重新檢視。
4. **可信度分級**：本檔各條目標示了 🟢 官方規則 / 🟡 回推規則。**引用 🟡 條目時，必須在報告中一併說明其為回推結果。**

## 1. 基本欄位（依序拆解）🟢

### 長度 (Length)
型號最前方的 **2〜3 位數字**。

| 編碼 | 判讀 | 備註 |
|---|---|---|
| `72` | 7 ft 2 in | 2 位數：第 1 位=呎，第 2 位=吋 |
| `83` | 8 ft 3 in | 同上 |
| `80` | 8 ft 0 in | 同上 |
| `610` | 6 ft 10 in | **3 位數**：第 1 位=呎，後 2 位=吋（吋數 ≥ 10 時使用） |
| `711` | 7 ft 11 in | 同上 |

⚠️ **2 位數 vs 3 位數的判別**：若第 2 位數字之後緊接的仍是數字，且組合起來為 10〜11，則屬 3 位數編碼。例如 `7112...` → `711` = 7'11"，而非 `71` = 7'1"。**務必用官方全長規格反向驗證。**

### 繼數 (Pieces)
緊接在長度後的數字/字母。

| 編碼 | 判讀 |
|---|---|
| `1` | One-piece（2017 年後含握把繼 Grip Joint） |
| `2` | Two-piece |
| `4` | Four-piece |
| `T` | Telescopic（振出） |

### 力量 (Power)
緊接在繼數後的字母。

`UL` / `L` / `ML` / `M` / `MH` / `H` / `XH` 等。

- **斜線標示**（如 `M/MH`）：斜線前為 Tip（竿先）力量，斜線後為 Butt（元端）力量。
- **`+` 修飾符**：見第 2 節。

### 調性 (Taper)
力量之後的字母。

| 編碼 | 判讀 |
|---|---|
| `S` | Slow taper |
| `R` | Regular taper |
| `F` | Fast taper |
| `X` | Extra Fast taper |

**官方出處** 🟢：DAIWA 官網託管之「**ロッド品番の読み解き方**」（リベリオン ルアー適合表 PDF）原文——

> ④テーパー ： S=スローテーパー　R=レギュラーテーパー　F=ファストテーパー　X=エクストラファストテーパー

<https://www.daiwa.com/jp/product/-/media/DF47A18A61E94238AFD5D02705EEC2C1.ashx>

⚠️ 該文件屬**リベリオン**系列。套用至 Heartland 屬**推論**，惟 Heartland 全系列型號皆吻合此文法（722MRB-20、752HRB-21、802MHRB-21、7112MRB-25、722LRS-21 等），支撐度高。

🔴 **調性是原廠標示，但標在「型號字串」裡，不在規格表裡。**
Heartland 規格表的完整欄位為：`全長／継数／ジョイント仕様／仕舞寸法／標準自重／先径・元径／ルアー重量／適合ライン ナイロン／適合ライン PE／カーボン含有率／価格／JAN`——**沒有** アクション／テーパー／調子 欄位。

→ 官網規格表查不到獨立的 action 欄位**是正常現象，不代表解碼有誤**。
→ 上表四個字母（`S`/`R`/`F`/`X`）有官方 key 背書，報告中**可以**陳述「原廠調性標示為 ◯」。
→ ⚠️ **但僅限上表已列出的字元。** 原廠會不定期在型號中加入未公佈定義的字元或修飾符（例：`722MLRSS-24` 多出來的 `S`），那些一律依 §0 原則 2 處理（揭露、不臆測），**不得與有官方背書的欄位混在一起，一併稱為「原廠標示」**。

- **斜線標示**（如 `F/R`）：Tip 為 F 調，Butt 為 R 調。

### 種類 (Rod Type)
調性之後的字母（**型號主體的最後一個字母**）。

| 編碼 | 判讀 |
|---|---|
| `B` | Baitcasting（槍柄） |
| `S` | Spinning（紡車） |

### 機能技術 (Features)
位於型號後綴（破折號 `-` 之後）。

| 編碼 | 判讀 | 對應技術字典條目 |
|---|---|---|
| `SV` | SVF Compile-X | `SVF COMPILE-X` |
| `AGS` | Air Guide System | `AGS (Air Guide System)` |
| `SMT` | Super Metal Top | `SMT（SuperMetalTop）` |
| `ST` | Solid Tip | （觸發 Step 3；**竿先之具體技術需另行確認**，見下方注意） |

⚠️ **`-ST` 的重要限制**：`-ST` 僅宣告「實心竿先」這個**結構事實**，**不等於宣告採用何種竿先技術**。字典中 `MEGA TOP`（實心碳纖維）與 `SMT`（鈦合金）物理特性差異極大（後者在 5℃ 以下會變軟）。若官方文案未指名，**不得臆測屬於何者**。

⚠️ **後綴為空 ≠ 技術貧乏**：DAIWA 僅將旗艦級識別技術掛在型號上。`HVF` 系碳布、`X45`、`3DX`、`V-JOINT`、`TUBULAR POWER SLIM` 等**均不上型號**，須由官方文案取得。

### 年份 (Year)
型號最後方的**兩位數字**。例：`21` = 2021 年式、`25` = 2025 年式。

## 2. 修飾符與例外欄位

### `+`（力量欄位後綴）🟡 回推規則

**判讀：在該力量階級之上「半階提升」（ハーフランク / half rank up）。**

- `UL+` → 介於 `UL` 與 `L` 之間
- `ML+` → 介於 `ML` 與 `M` 之間

**依據**：DAIWA 官方文案於 `HL 702UL+FS-ST23` 的介紹中明確記載「（前代機種）よりも**ハーフランクパワーアップ**させたブランク」。此為**原廠針對該型號的直接敘述**。

**可信度分級**：
- 🟢 **702UL+FS-ST23** — 原廠明文定義，可直接採用。
- 🟡 **其他帶 `+` 的型號**（如 722ML+FB-ST20、772ML+FS-22）— 屬同廠同系列同世代之**外推**，原廠未針對各該型號說明。
  → **引用時必須在報告中註明為外推**，或保守地以「該階級以上、未達次一階級」的區間處理。

（上列型號在此僅作為**外推邊界的標示**。各竿的官方文案原文與其他機種級事實，見對應系列的產品特性檔。）

### 額外的 `S`（介於調性與種類之間）🟡 回推規則

**判讀：`S` = Special（該型號為經典名竿「◯◯スペシャル」的現代復刻）。**

出現位置：`力量` → `調性` → **`S`** → `種類`

| 型號 | 拆解 | 官方文案指名之前身 |
|---|---|---|
| `722LRSB-24` | 72 / 2 / **L** / **R** / **S** / **B** | スモールプラグ**スペシャル**（Small Plug Special） |
| `722MLRSS-24` | 72 / 2 / **ML** / **R** / **S** / **S** | ハマスピニング**スペシャル**（Hama Spinning Special） |

**依據**：兩支帶此字元的型號，官方文案均明確指出其為某款「**スペシャル**」名竿的現代化復刻。目前全系列僅此二例，且**兩支的唯一共同點就是「具名スペシャル復刻」**。

**排除的其他可能**：
- ❌ `S` = Solid：722LRSB-24 官方明寫是把初代**全實心 blank 改為チューブラー化（空心化）**，直接矛盾。

**可信度分級**：🟡 **回推規則**。DAIWA 未公佈此字元的官方定義。
→ **引用時必須在報告中註明為回推結果。**

> 🔴 **誠實聲明（務必照實轉述，不得美化）**
> 這個判讀**無法從命名文法本身推導出來**——官方 key 的六個欄位裡根本沒有這一欄。
> 它唯一的依據，是「兩支帶此字元的竿，官方文案都指名了スペシャル前身」這**一個相關性**。
> `S` 同樣可能只是該世代的內部編碼、產線識別，或其他原廠沒說的東西。
> **這是猜的。** 報告中必須讓讀者看得出來這是猜的。

（上表的用途是驗證 `S` 的**插入位置**。各竿的官方文案原文與證偽判準，見對應系列的產品特性檔。）

#### 併存的競爭假說：`RS` = Regular Slow（單一複合調性代碼）⚠️ 已知，但本 Skill 不採用

存在另一種解讀：`RS` 不是兩個欄位，而是**一個複合調性代碼**（Regular→Slow）。
**此假說尚未被完全排除**，記錄於此以供日後修正。**目前一律以上方 `R`(調性) + `S`(Special) 為準。**

**不採用的理由**（以下皆為非循環證據，不預設調性欄位歸屬）：

1. **兩支 RS 竿的錐度比分居 R 群的兩端**

   兩支帶 `RS` 的竿，一支 Ratio **5.88**（全系列最低，軟於所有官方 `R`），另一支 **7.23**（快於所有官方 `R`），
   之間隔著**五支**官方標 `R` 的竿。同一個調性代碼不可能同時代表「比 R 慢」與「比 R 快」。
   （低值那支經進階診斷確認**非失真值**：元端過剩指數 54.4、元徑 9.4mm，兩項均在正常範圍。）

   → 逐型號的先徑／元徑／Ratio 明細屬**機種級規格數據**，不參與型號字串拆解，故不登錄於本檔；
   　 見對應系列的產品特性檔（`daiwa_<系列>_features.md`）之「錐度比實測表」。

2. **官方文案與 Slow 直接矛盾**
   722LRSB-24 官方明寫採用「**硬めのティップ**」（偏硬竿先），與 Slow taper 的軟竿先衝突。

3. **DAIWA 對「複合欄位」已有既定語法**
   官方 key 的 ③パワー 以斜線表示複合（`"/"の前がティップ、後がバット`）。若要表達複合調性，既有語法應寫作 `722MLR/SS-24`。
   且官方リベリオン適合表 40+ 支型號中，**調性欄一律單字母，無任何雙字母例外**。

**🔴 嚴禁以「彎得深所以應該是 Slow」來支持此假說。**
官方文案稱 `702UL+FS-ST23` 為「ハートランド**史上最軟調子**」，而其調性字母為 **`F`**。
→ DAIWA 的調性字母追蹤的是**彎曲點位置**，不是軟硬程度。**以軟硬度反推調性字母，在 DAIWA 體系中無效。**

**證偽判準**：村上晴彦的第三支名竿為**常吉スペシャル**。若日後推出其復刻版——
- 代碼為 `F` + `S` + 種類（如 `722MFSB`）→ **RS 複合調假說推翻**，本小節可刪除。
- 代碼仍為 `RS` → 反須重新檢視 Special 假說。

## 3. 尚未涵蓋的欄位（發現時請更新本檔）

目前已知本檔**尚未涵蓋**的情況：

- Heartland 以外系列（如 Steez、Blazon、Tatula 等）是否沿用完全相同的規則，**未經驗證**。
- 型號前綴（如 `HL` = Heartland）之完整廠牌／系列代碼對照表**尚未建立**。
- 3 位數以上的長度編碼（若存在）未涵蓋。

遇到上述或任何其他未涵蓋情況時，**一律依第 0 節原則 2 處理：揭露、不臆測、不作為推演依據。**
