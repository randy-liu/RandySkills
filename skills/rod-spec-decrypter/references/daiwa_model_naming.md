# ダイワ（DAIWA）型號命名規則辭典

這份文件是 DAIWA 釣竿**型號字串的解碼規則**，供 `SKILL.md` 的 **Step 0（型號自動解碼）**使用。

> 🔴 **與 `daiwa_technology.md` 的分工**
> 本檔 = **型號字串怎麼拆**（一次性流程，Step 0 使用）
> `daiwa_technology.md` = **技術名詞是什麼意思**（查表，Step 2 反覆使用）
> 分析 DAIWA 釣竿時，**兩份都必須載入**。

---

## 0. 使用原則（務必遵守）

1. **逐欄位比對，不得跳過**：型號字串必須從左到右依序拆解，每個字元都要有歸屬。
2. **🔴 遇到本檔未涵蓋的字元，一律不臆測**：
   直接在報告中揭露「**該欄位不在 Skill 命名字典庫中，需要更新 Skill**」，並且**該字元不得作為後續任何物理推演的依據**。
3. **確認長度吻合**：拆解出的長度應與官方「全長」規格互相驗證（1 ft = 0.3048 m）。若不吻合，代表拆解有誤，須重新檢視。
4. **可信度分級**：本檔各條目標示了 🟢 官方規則 / 🟡 回推規則。**引用 🟡 條目時，必須在報告中一併說明其為回推結果。**

## 1. 基本欄位（依序拆解）🟢

### 長度 (Length)
型號最前方的 **2〜3 位數字**。

| 編碼 | 判讀 | 備註 |
|---|---|---|
| `72` | 7 ft 2 in | 2 位數：第 1 位=呎，第 2 位=吋 |
| `83` | 8 ft 3 in | 同上 |
| `80` | 8 ft 0 in | 同上 |
| `610` | 6 ft 10 in | **3 位數**：第 1 位=呎，後 2 位=吋（吋數 ≥ 10 時使用） |
| `711` | 7 ft 11 in | 同上 |

⚠️ **2 位數 vs 3 位數的判別**：若第 2 位數字之後緊接的仍是數字，且組合起來為 10〜11，則屬 3 位數編碼。例如 `7112...` → `711` = 7'11"，而非 `71` = 7'1"。**務必用官方全長規格反向驗證。**

### 繼數 (Pieces)
緊接在長度後的數字/字母。

| 編碼 | 判讀 |
|---|---|
| `1` | One-piece（2017 年後含握把繼 Grip Joint） |
| `2` | Two-piece |
| `4` | Four-piece |
| `T` | Telescopic（振出） |

### 力量 (Power)
緊接在繼數後的字母。

`UL` / `L` / `ML` / `M` / `MH` / `H` / `XH` 等。

- **斜線標示**（如 `M/MH`）：斜線前為 Tip（竿先）力量，斜線後為 Butt（元端）力量。
- **`+` 修飾符**：見第 2 節。

### 調性 (Taper)
力量之後的字母。

| 編碼 | 判讀 |
|---|---|
| `S` | Slow taper |
| `R` | Regular taper |
| `F` | Fast taper |
| `X` | Extra Fast taper |

- **斜線標示**（如 `F/R`）：Tip 為 F 調，Butt 為 R 調。

### 種類 (Rod Type)
調性之後的字母（**型號主體的最後一個字母**）。

| 編碼 | 判讀 |
|---|---|
| `B` | Baitcasting（槍柄） |
| `S` | Spinning（紡車） |

### 機能技術 (Features)
位於型號後綴（破折號 `-` 之後）。

| 編碼 | 判讀 | 對應技術字典條目 |
|---|---|---|
| `SV` | SVF Compile-X | `SVF COMPILE-X` |
| `AGS` | Air Guide System | `AGS (Air Guide System)` |
| `SMT` | Super Metal Top | `SMT（SuperMetalTop）` |
| `ST` | Solid Tip | （觸發 Step 3；**竿先之具體技術需另行確認**，見下方注意） |

⚠️ **`-ST` 的重要限制**：`-ST` 僅宣告「實心竿先」這個**結構事實**，**不等於宣告採用何種竿先技術**。字典中 `MEGA TOP`（實心碳纖維）與 `SMT`（鈦合金）物理特性差異極大（後者在 5℃ 以下會變軟）。若官方文案未指名，**不得臆測屬於何者**。

⚠️ **後綴為空 ≠ 技術貧乏**：DAIWA 僅將旗艦級識別技術掛在型號上。`HVF` 系碳布、`X45`、`3DX`、`V-JOINT`、`TUBULAR POWER SLIM` 等**均不上型號**，須由官方文案取得。

### 年份 (Year)
型號最後方的**兩位數字**。例：`21` = 2021 年式、`25` = 2025 年式。

## 2. 修飾符與例外欄位

### `+`（力量欄位後綴）🟡 回推規則

**判讀：在該力量階級之上「半階提升」（ハーフランク / half rank up）。**

- `UL+` → 介於 `UL` 與 `L` 之間
- `ML+` → 介於 `ML` 與 `M` 之間

**依據**：DAIWA 官方文案於 `HL 702UL+FS-ST23` 的介紹中明確記載「（前代機種）よりも**ハーフランクパワーアップ**させたブランク」。此為**原廠針對該型號的直接敘述**。

**可信度分級**：
- 🟢 **702UL+FS-ST23** — 原廠明文定義，可直接採用。
- 🟡 **其他帶 `+` 的型號**（如 722ML+FB-ST20、772ML+FS-22）— 屬同廠同系列同世代之**外推**，原廠未針對各該型號說明。
  → **引用時必須在報告中註明為外推**，或保守地以「該階級以上、未達次一階級」的區間處理。

### 額外的 `S`（介於調性與種類之間）🟡 回推規則

**判讀：`S` = Special（該型號為經典名竿「◯◯スペシャル」的現代復刻）。**

出現位置：`力量` → `調性` → **`S`** → `種類`

| 型號 | 拆解 | 官方文案指名之前身 |
|---|---|---|
| `722LRSB-24` | 72 / 2 / **L** / **R** / **S** / **B** | スモールプラグ**スペシャル**（Small Plug Special） |
| `722MLRSS-24` | 72 / 2 / **ML** / **R** / **S** / **S** | ハマスピニング**スペシャル**（Hama Spinning Special） |

**依據**：兩支帶此字元的型號，官方文案均明確指出其為某款「**スペシャル**」名竿的現代化復刻。

**排除的其他可能**：
- ❌ `S` = Solid：722LRSB-24 官方明寫是把初代**全實心 blank 改為チューブラー化（空心化）**，直接矛盾。
- ❌ `S` = Slow taper：調性欄位已被 `R` 佔用；且 722LRSB-24 的錐度比為 7.23（中庸偏快），與 Slow 不符。

**可信度分級**：🟡 **回推規則**。DAIWA 未公佈此字元的官方定義。
→ **引用時必須在報告中註明為回推結果。**

## 3. 尚未涵蓋的欄位（發現時請更新本檔）

目前已知本檔**尚未涵蓋**的情況：

- Heartland 以外系列（如 Steez、Blazon、Tatula 等）是否沿用完全相同的規則，**未經驗證**。
- 型號前綴（如 `HL` = Heartland）之完整廠牌／系列代碼對照表**尚未建立**。
- 3 位數以上的長度編碼（若存在）未涵蓋。

遇到上述或任何其他未涵蓋情況時，**一律依第 0 節原則 2 處理：揭露、不臆測、不作為推演依據。**
