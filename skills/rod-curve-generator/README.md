# Rod Curve Generator

這個 Skill 是一套專業的「釣竿曲線產生器」，專門用來將釣竿的幾何與材質參數，透過真實物理引擎運算，繪製成專業級的彎曲曲線圖。

## 核心功能

本工具內建雙模產圖系統，提供兩種截然不同的分析視角：

1. **ZENAQ 風格圖表 (`plot-zenaq`)**
   - **45度角持竿模擬**：模擬實戰中將釣竿上舉 45 度角的受力曲線。
   - **動態負載計算**：自動讀取釣竿的 `Lure_Rating`（路亞克數），推演出最適合的測試重量區間。
   - **無干涉儀表板排版**：採用左右分離的 Dashboard 佈局，將「數據繪圖區」與「文字資訊區」進行物理隔離，確保硬調竿在輕負載下也絕對不會與文字重疊。
   - **產出內容**：包含所有釣竿的同重量對比圖（Comparison），以及單把釣竿的多負載漸進圖（Progressive）。

2. **工程分析版圖表 (`plot-engineering`)**
   - **水平極限測試**：從 0 度角（水平）出發，模擬極端環境下的受力彎曲。
   - **固定壓力基準**：不論釣竿調性，統一施加 100g、250g、500g、1000g 的重度負載，測試竿身的反發力與極限強度。
   - **專業工程方塊**：在畫面左下方附上超詳細的規格表（長度、先徑、元徑、路亞負載等），如同官方出廠的規格文件。

## 使用方式

本工具已針對 AI 進行高度整合與指令封裝 (`SKILL.md`)，未來只需要直接吩咐 AI：
> 「幫我把 `RodAction` 資料夾裡面的釣竿，用 `rod-curve-generator` 畫出 ZENAQ 圖跟工程圖」

AI 就會在背景自動執行以下三個標準步驟：
1. **資料萃取 (`extract`)**：從各個釣竿的 Markdown 報告中精準抓取規格。若發現必填欄位遺漏，AI 會嚴格報錯並暫停，**絕不憑空捏造數據**。
2. **自動計算與繪圖 (`plot-zenaq` / `plot-engineering`)**：依據萃取出的數據，透過隔離的 Python 虛擬環境 (`uv run`) 進行物理運算，不弄髒全域環境。
3. **歸檔輸出**：將產生的精美圖表自動存放到指定的資料夾中。

## 依賴需求
底層腳本採用 PEP 723 內聯中繼資料標準宣告依賴 (`numpy`, `matplotlib`, `pillow`)，並由 `uv` 自動管理，無需手動安裝任何套件。
